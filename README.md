# IAX Phone — IAX2-софтфон для Android

Собственная реализация протокола IAX2 (RFC 5456) на Kotlin, без нативных библиотек.

## Что умеет
- Регистрация на сервере (REGREQ → REGAUTH → REGACK), MD5-авторизация, CALLTOKEN, автоматическая перерегистрация.
- Исходящие и входящие вызовы, ответ, отбой, «занято», DTMF.
- Голосовая почта: число новых сообщений на «Звонилке», звонок на почту кнопкой или долгим нажатием «1» (номер настраивается, по умолчанию *97).
- Голос G.711 µ-law / A-law и GSM 06.10, 20 мс, полные и мини-кадры, джиттер-буфер, эхоподавление и шумоподавление Android.
- PING/PONG, LAGRQ/LAGRP, POKE (qualify), подтверждения и повторная отправка кадров.
- Foreground-сервис держит регистрацию в фоне; входящий вызов показывается уведомлением с кнопками «Ответить» / «Отклонить».

## Интерфейс
Верхняя панель с четырьмя вкладками:
- **Звонилка** — номер, круглая клавиатура (долгое нажатие «0» — «+»), зелёная кнопка вызова; пустой номер + кнопка вызова подставляет последний набранный. Строка статуса регистрации сверху открывает настройки подключения.
- **Журнал** — история звонков (входящие, исходящие, пропущенные, длительность); меню записи: позвонить, в набор, добавить в контакты, удалить.
- **Контакты** — собственная записная книжка приложения (имя + номер), добавление, изменение, удаление, звонок.
- **Настройки** → **Общие** (тема: как в системе, светлая, тёмная; обновления: проверка релизов на GitHub, загрузка и установка), **Подключение** (сервер, порт, логин, пароль, Caller ID, кнопка подключения; подключение восстанавливается при следующем запуске) и **Логи** (журнал протокола IAX2 с копированием и очисткой).

Во время вызова поверх вкладок открывается экран разговора: имя/номер, таймер и кодек, кнопки «Микрофон», «Клавиатура» (DTMF), «Динамик», «Ответить» / «Завершить».

## Установка
Готовый APK — на странице [Releases](https://github.com/alex-rek/IaxPhone/releases): скачайте `IaxPhone-<версия>.apk` на телефон и установите (Android 8.0+, потребуется разрешить установку из неизвестных источников).

## Сборка
```
gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
gradlew testDebugUnitTest      # тесты, включая интеграционный с tools/iax_test_server.py
```
Требуется Android Studio (JDK из `jbr`), SDK 36. minSdk 26 (Android 8).

Release-сборка (`gradlew assembleRelease`) подписывается ключом из `~/.android-keys/iaxphone-release.properties`
(поля `storeFile`, `storePassword`, `keyAlias`, `keyPassword`; другой путь — `-Piaxphone.signing=...`).
Без этого файла release-APK собирается неподписанным.

## Структура
- `app/src/main/java/com/glaude/iaxphone/iax/` — стек IAX2 на чистом Kotlin (можно вынести в отдельную библиотеку).
  - `IaxClient.kt` — транспорт, регистрация, вызовы, надёжная доставка.
  - `Frames.kt`, `InfoElements.kt`, `IaxConstants.kt` — формат кадров и IE.
  - `G711.kt` — кодек.
- `audio/AudioEngine.kt` — микрофон/динамик (AudioRecord/AudioTrack).
- `Phone.kt` — связка протокола, звука и UI; `SoftphoneService.kt` — фоновый сервис.
- `MainActivity.kt` — вкладки и экран разговора; `ConnectionActivity.kt`, `LogActivity.kt` — разделы настроек; `Store.kt` — журнал звонков и контакты.
- `tools/iax_test_server.py` — тестовый IAX2-сервер для проверки без Asterisk.

## Тестовый сервер
```
python tools/iax_test_server.py --port 4569 --user 100:secret
```
`--codecs gsm` — сервер разрешит только GSM (как многие провайдеры); по умолчанию `ulaw,alaw`.
`--voicemail 3:17` — сообщать при регистрации о 3 новых и 17 прослушанных сообщениях.
В эмуляторе укажите сервер `10.0.2.2`, логин `100`, пароль `secret`.
Номера: `600` эхо, `700` тон, `486` занято, `800` — сервер перезвонит вам.

## Пример настройки Asterisk (`iax.conf`)
```
[100]
type=friend
host=dynamic
secret=secret
auth=md5
context=from-internal
disallow=all
allow=ulaw
allow=alaw
transfer=no        ; клиент не поддерживает прямую передачу медиа
qualify=yes
requirecalltoken=yes
```

## Ограничения
- Кодеки: G.711 и GSM (Opus/G.722/G.729/iLBC не реализованы).
- Нет шифрования IAX2 и RSA-авторизации; пароль хранится в SharedPreferences открытым текстом.
- Одна линия: второй входящий получает «занято». Нет удержания и перевода вызова.
- Не используется Android Telecom (ConnectionService): система не знает о вызовах как о «телефонных».
- В режиме Doze Android может усыплять сеть — для надёжного приёма входящих в фоне нужен push-механизм или исключение из оптимизации батареи.
